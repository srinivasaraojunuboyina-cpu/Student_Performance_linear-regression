# Student_Performance_linear-regression
# Student Performance Prediction Using Machine Learning

## Project Description

This project focuses on predicting student academic performance using Machine Learning regression algorithms. The primary objective is to analyze the relationship between different student-related features and academic performance while developing accurate predictive models.

The project implements and compares three supervised machine learning algorithms: **Linear Regression, Lasso Regression, and Ridge Regression**.

It covers the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, prediction, and performance evaluation.

## Key Features

- Data cleaning and preprocessing to improve dataset quality.
- Exploratory Data Analysis (EDA) to identify important patterns and relationships.
- Feature encoding and scaling to prepare data for machine learning.
- Implementation of Linear Regression, Lasso Regression, and Ridge Regression.
- Comparison of regression algorithms to identify the best-performing model.
- Model evaluation using R² Score, Mean Absolute Error (MAE), Mean Squared Error (MSE), and Root Mean Squared Error (RMSE).
- Performance analysis to understand prediction accuracy and model reliability.

## Model Performance

| Algorithm | R² Score | MAE | RMSE |
|---|---:|---:|---:|
| Linear Regression | 0.9884 | 1.6470 | 2.0751 |
| Lasso Regression | 0.9848 | 1.8910 | 2.3752 |
| Ridge Regression | 0.9884 | 1.6470 | 2.0751 |

## Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, and Machine Learning Regression Algorithms.

## Project Outcome

Linear Regression and Ridge Regression achieved approximately **98.84% R²**, demonstrating strong predictive performance on the evaluation dataset. Lasso Regression also performed well, with an R² score of approximately 98.48%.

The project demonstrates practical knowledge of supervised machine learning, regression modeling, regularization techniques, data preprocessing, and model evaluation.
